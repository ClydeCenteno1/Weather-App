# Weather App

A responsive weather dashboard built with HTML, Tailwind CSS, and Axios. Users can search for a city and receive current weather details, temperature, and a weather icon from the OpenWeatherMap API.

## Features

- City-based weather lookup
- Current temperature display in Celsius
- Weather condition and description
- Dynamic weather icon rendering
- Responsive layout with Tailwind CSS
- Background image styling for polished visual appeal

## Technologies

- HTML
- JavaScript
- Tailwind CSS (CDN)
- Axios (CDN)
- OpenWeatherMap API

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ClydeCenteno1/Weather-App.git
   ```
2. Copy `config.example.js` to `config.js` and replace the placeholder API key with your OpenWeather API key.
3. Open the project folder in your code editor.
4. Open `index.html` in a browser or use a local development server.

## Usage

1. Enter a city name in the search field.
2. Submit the form.
3. View the city name, country, temperature, weather condition, and description.

## Notes

- This project uses Tailwind CSS and Axios via CDN links.
- Weather data is fetched from the OpenWeatherMap API.
